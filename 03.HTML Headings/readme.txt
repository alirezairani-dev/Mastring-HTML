HTML Headings :

- HTML Headings are titles or subtitles that you want to display on a webpage.

- HTML Headings are difined with the "h1" to "h6" tags.

- "h1" defines the most important heading."h6" defines the least important heading.

Note : Browsers automatically add some white space (a margin) before and after headings.

Headings Are Important :

- Search engines use the headings to index the structure and content of your web pages.

- "h1" heading should be used for main headings, followed by "h2" heading, then the less important "h3", and so on.
    - For example :
        "<h1>" - Page title
        "<h2>" - Section titles
        "<h3>" - Sub-sections
