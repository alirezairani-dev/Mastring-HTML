HTML is the stundard markup language for creating web pages.

HTML stands for Hyper Text markup language.

- The "<!DOCTYPE html>" declaration defines that this document is an HTML5 document.
- The "<HTML>" element is the root element of an HTML page.
- The "<head>" element contains the meta information about the HTML page.
- The "<title>" element specifise a title for the HTML page (which is shown in the browser's title bar or in page's tab).
- The "<body>" element defines the document's body, and is a container for all the visible contents, such as heading, paragraphs, images, hyperlinks, tables, lists, etc.
- The "<h1>" element defines a large heading.
- The "<p>" element defines a paragraph.

What is an HTML Element ?
- An HTMl Element is defined by a start tag, some content, and an end tag.

<tagname>Content goes here...</tagname>

Note : Some HTML element have no content (like the <br> element)These element are called empty element. Empty element have no end tag !

Web Browsers
The purpose of a web browser (Chrome, Edge, Firefox, Safari) is to read HTML documents and display them correctly.

Note: The content inside the "<body>" section will be displayed in a browser.
